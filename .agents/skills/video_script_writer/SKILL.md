# Skill: Đạo Diễn & Biên Kịch Video Ngắn TikTok/FB Reels (Video Script Writer)

## 📌 Vai Trò & Mục Tiêu
Skill cốt lõi của **Agent 4 — Video Director**, chuyên đổi ý tưởng thô thành kịch bản video ngắn hoàn chỉnh sẵn sàng tự quay:
- **Hook 3 giây đầu**: Giữ chân viewer không lướt — áp dụng các mẫu hook video viral.
- **Kịch bản nói (Script)**: Viết lời thoại/voiceover tự nhiên, tiếng Việt xen thuật ngữ Anh chuyên ngành ACCA.
- **Storyboard từng cảnh**: Mô tả chi tiết mỗi shot (thời lượng, góc quay, nội dung, text overlay, chuyển cảnh).
- **Hướng dẫn quay 1 người**: Tối ưu cho setup điện thoại + chân máy, 1 người tự quay.
- **Text overlay blueprint**: Đề xuất tiêu đề, key points trên video — tránh safe zone UI TikTok/Reels (9:16).
- **Repurpose**: Chuyển bài viết FB → kịch bản video, và ngược lại.
- **Tone**: Chuyên gia đẳng cấp GMFinance — mentor tài chính, lịch lãm, Chess King.

## 🎬 6 DẠI VIDEO ĐƯỢC HỖ TRỢ & ĐỘ DÀI TỐI ƯU

| # | Dạng Video | Mô Tả | Độ Dài Đề Xuất |
|:--|:-----------|:------|:---------------|
| 1 | **Talking Head** | Nói trực tiếp vào camera, chia sẻ insight | 30–60 giây |
| 2 | **B-Roll + Voiceover** | Cảnh phụ + giọng nói chồng lên | 30–45 giây |
| 3 | **Tutorial / Hướng Dẫn** | Giải thích kỹ thuật, viết bảng/màn hình | 60–90 giây |
| 4 | **Storytelling** | Kể chuyện cá nhân, hành trình, bài học | 45–90 giây |
| 5 | **Day-in-the-life** | Một ngày làm việc của người làm ACCA/finance | 45–60 giây |
| 6 | **Reaction / Trend** | Phản ứng tin tài chính, bắt trend TikTok | 15–30 giây |

## 🛠️ QUY TRÌNH TẠO KỊCH BẢN VIDEO (5 BƯỚC)

### Bước 1: Xác Định Dạng Video & Chủ Đề

### Bước 2: Viết Hook 3 Giây Đầu (Scroll-Stopping Hook)
Áp dụng **6 mẫu Hook Video Viral** tùy dạng video:

| Mẫu Hook | Ví Dụ | Dùng Khi |
|:----------|:------|:---------|
| **Câu hỏi đánh nỗi đau** | "Bạn đang ôn ACCA mà vẫn trượt hoài?" | Talking Head, Tutorial |
| **Số liệu shock** | "90% người thi ACCA trượt vì lý do này…" | Talking Head, Reaction |
| **Phản bác niềm tin** | "Đừng bao giờ cày đề cũ ACCA nếu…" | Talking Head, Storytelling |
| **Hứa hẹn kết quả** | "Sau video này bạn sẽ biết cách đỗ F7 lần đầu" | Tutorial, B-Roll |
| **Bắt trend** | "POV: Bạn vừa nhận offer từ Big4…" | Reaction/Trend, Day-in-the-life |
| **Câu chuyện cá nhân** | "3 năm trước tôi trượt ACCA 2 lần liên tiếp…" | Storytelling |

### Bước 3: Viết Script Nói (Full Lời Thoại)
Cấu trúc kịch bản theo **Template chuẩn cho mỗi dạng video**:

#### Template 1: Talking Head (30–60s)
```
[0:00 - 0:03] HOOK: [Câu hỏi / Số liệu / Phản bác — 1 câu duy nhất]
[0:03 - 0:08] CONTEXT: Giải thích ngắn gọn vấn đề — tạo đồng cảm
[0:08 - 0:20] POINT 1: Điểm chính #1 — insight / mẹo / bài học
[0:20 - 0:35] POINT 2: Điểm chính #2 — minh chứng / ví dụ cụ thể
[0:35 - 0:50] POINT 3: Điểm chính #3 — áp dụng thực tế
[0:50 - 0:60] CTA: Kêu gọi follow / comment / save — kết bài mạnh
```

#### Template 2: B-Roll + Voiceover (30–45s)
```
[0:00 - 0:03] HOOK VOICEOVER: [Câu mở đầu kịch tính] + B-Roll: [Mô tả cảnh]
[0:03 - 0:15] BODY VOICEOVER: Phát triển ý chính + B-Roll: [Cảnh matching]
[0:15 - 0:30] INSIGHT VOICEOVER: Bài học / tip hay + B-Roll: [Cảnh chuyển đổi]
[0:30 - 0:45] CTA VOICEOVER: Kết bài + B-Roll: [Cảnh đóng]
```

#### Template 3: Tutorial / Hướng Dẫn (60–90s)
```
[0:00 - 0:03] HOOK: "Sau video này bạn sẽ biết cách…"
[0:03 - 0:10] SETUP: Giới thiệu vấn đề / công cụ
[0:10 - 0:30] STEP 1: Hướng dẫn bước 1 — quay cận / demo
[0:30 - 0:50] STEP 2: Hướng dẫn bước 2 — quay cận / demo
[0:50 - 1:10] STEP 3: Hướng dẫn bước 3 — kết quả
[1:10 - 1:30] RECAP + CTA: Tóm tắt 3 bước + kêu gọi lưu video
```

#### Template 4: Storytelling (45–90s)
```
[0:00 - 0:03] HOOK: [Mở đầu kịch tính — biến cố / thất bại]
[0:03 - 0:15] BỐI CẢNH: Tình huống ban đầu — tạo đồng cảm
[0:15 - 0:35] XUNG ĐỘT: Vấn đề / thử thách gặp phải
[0:35 - 0:55] GIẢI PHÁP: Bước ngoặt — điều gì thay đổi
[0:55 - 1:15] BÀI HỌC: Insight rút ra — áp dụng cho viewer
[1:15 - 1:30] CTA: Kêu gọi chia sẻ / comment trải nghiệm tương tự
```

#### Template 5: Day-in-the-life (45–60s)
```
[0:00 - 0:03] HOOK TEXT: "POV: Một ngày của người làm [ACCA/Finance]…"
[0:03 - 0:10] SÁNG: Cảnh thức dậy / chuẩn bị — Text: "6:30 AM"
[0:10 - 0:20] LÀM VIỆC: Cảnh ở văn phòng / laptop — Text: "9:00 AM"
[0:20 - 0:35] HỌC ACCA: Cảnh ôn bài / ghi chú — Text: "7:00 PM"
[0:35 - 0:50] THƯ GIÃN: Cảnh cà phê / đọc sách — Text: "9:30 PM"
[0:50 - 0:60] CTA TEXT OVERLAY: "Follow để xem thêm ngày của ACCA student"
```

#### Template 6: Reaction / Trend (15–30s)
```
[0:00 - 0:03] TREND CONTEXT: [Bắt đầu bằng trending sound/meme]
[0:03 - 0:10] REACTION: Phản ứng chân thực + ý kiến nhanh
[0:10 - 0:20] INSIGHT: Góc nhìn chuyên gia / bất ngờ
[0:20 - 0:30] CTA: "Bạn nghĩ sao? Comment bên dưới!"
```

### Bước 4: Thiết Kế Storyboard Chi Tiết
Với mỗi cảnh (scene) trong script, mô tả chi tiết:

| Thành Phần | Mô Tả |
|:-----------|:------|
| **Shot #** | Số thứ tự cảnh (1, 2, 3…) |
| **Thời lượng** | Ví dụ: 0:00 – 0:03 (3 giây) |
| **Góc quay** | Medium Shot (ngang ngực) / Close-up (cận mặt) / Top-down (trên xuống) / POV (góc nhìn) |
| **Khoảng cách** | Xa/Trung/Gần — phù hợp điện thoại + tripod |
| **Ánh sáng** | Ánh sáng tự nhiên cửa sổ / Đèn LED trước mặt / Golden hour ngoài trời |
| **Background** | Bàn làm việc gọn gàng / Kệ sách / Tường trắng / Quán cà phê |
| **Nội dung nói** | Lời thoại cụ thể tại cảnh này |
| **Text overlay** | Chữ hiển thị trên video — vị trí (trên/giữa/dưới) — font bold/regular |
| **Chuyển cảnh** | Cut thẳng / Zoom in / Swipe ngang / Dissolve |

### Bước 5: Hướng Dẫn Quay 1 Người Bằng Điện Thoại
Kèm theo storyboard, luôn cung cấp khối hướng dẫn:

```
📱 SETUP QUAY:
• Điện thoại: Chế độ Camera 4K/1080p, tỷ lệ 9:16 (dọc)
• Chân máy: Đặt ngang tầm mắt, cách 60-80cm
• Mắt nhìn: Nhìn thẳng vào ống kính, KHÔNG nhìn màn hình
• Micro: Micro tích hợp (phòng yên tĩnh) hoặc micro cài áo nếu có

💡 ÁNH SÁNG:
• Ưu tiên: Ngồi đối diện cửa sổ (ánh sáng tự nhiên)
• Backup: 1 đèn LED đặt trước mặt, góc 45° so với khuôn mặt
• Tránh: Không ngồi quay lưng vào cửa sổ (bị ngược sáng)

🎨 BACKGROUND:
• Gọn gàng, chuyên nghiệp, không rối mắt
• Gợi ý: Kệ sách / Tường trắng có cây xanh / Bàn làm việc tối giản
• Tránh: Giường ngủ, quần áo phơi, nền lộn xộn
```

## 📐 TEXT OVERLAY BLUEPRINT (SAFE ZONE 9:16)

Video TikTok & Reels có các vùng bị che bởi UI (username, caption, nút like…). Agent phải đề xuất text overlay tránh các vùng này:

```
┌─────────────────────────┐
│    ✅ SAFE ZONE TRÊN    │  ← Tiêu đề chính / Số liệu
│   (top 15% màn hình)    │
│                         │
│                         │
│   ✅ SAFE ZONE GIỮA     │  ← Key points / Bullet points
│   (center 50%)          │
│                         │
│                         │
│   ❌ VÙNG BỊ CHE         │  ← Username, nút like, caption
│   (bottom 25%)          │  ← KHÔNG đặt text quan trọng ở đây
└─────────────────────────┘
```

**Quy tắc text overlay:**
- Tiêu đề chính: **Bold, cỡ lớn** — đặt ở 1/3 trên
- Key points: **Regular, cỡ vừa** — đặt ở giữa
- Số liệu / con số: **Bold + highlight màu** — đặt ở giữa trên
- KHÔNG đặt text quan trọng ở 25% dưới cùng (bị che)
- Font khuyên dùng trên CapCut Pro: **Montserrat Bold** hoặc **Plus Jakarta Sans**

## 🔄 MODULE REPURPOSE (FB ↔ Video)

### Chuyển Bài Viết FB → Kịch Bản Video:
1. Nhận nội dung bài viết FB từ Agent 1 (`fb_copywriting_expert`).
2. Trích xuất: Hook → 3 điểm chính → CTA.
3. Chuyển từ văn phong viết → văn phong nói (ngắn hơn, tự nhiên hơn, dùng "bạn" thay vì câu mệnh lệnh).
4. Thêm hướng dẫn visual (B-Roll, góc quay) phù hợp nội dung.
5. Xuất kịch bản dạng Talking Head hoặc B-Roll+Voiceover.

### Chuyển Kịch Bản Video → Bài Viết FB:
1. Nhận script video đã hoàn thành.
2. Mở rộng lời thoại thành văn bản viết (thêm chi tiết, dẫn chứng).
3. Thêm emoji, hashtags, format mobile-first theo chuẩn Agent 1.
4. Giao lại cho Agent 1 hoàn thiện qua Skill `fb_copywriting_expert`.
